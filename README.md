# SoftITO | Veri Analitiği Eğitim Portföyü

İstanbul Ticaret Odası (İTO) bünyesindeki **SoftITO Yazılım-Bilişim Akademisi** Veri Analitiği eğitimi boyunca hazırladığım ödevleri ve projeleri bu depoda bir araya getiriyorum. Çalışmalar Python ile veri işleme, keşifsel veri analizi, görselleştirme ve etkileşimli analiz uygulamalarını kapsamaktadır.
